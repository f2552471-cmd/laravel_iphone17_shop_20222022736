## 🚀 About the Project
This project is a specialized E-Commerce platform designed specifically for the upcoming **iPhone 17**. It delivers a premium shopping user experience alongside a powerful full-featured **Admin Panel** to manage the entire store operations seamlessly.

### 🌟 Key Features
* **User Authentication & Role System:** Secure Login/Register system with specific roles (Admin vs. Regular User).
* **Premium Storefront:** High-fidelity catalog dedicated to showcasing the iPhone 17 with its dynamic technical specifications.
* **Comprehensive Admin Panel:** A dedicated dashboard for administrators to track metrics, manage users, and update store content.
* **Product & Order Management:** Full CRUD operations backend utilizing Laravel's Database ORM (Eloquent) and structured Migrations.

---

## 🛠️ Tech Stack & Requirements
* **Backend Framework:** Laravel
* **Database:** MySQL / PostgreSQL (Database ORM & Migrations)
* **Frontend Tools:** Vite, PostCSS (TailwindCSS/Bootstrap)
* **Package Manager:** Composer & NPM
